Business cards configurator (PHP).

GitHub (share with client): https://github.com/JesikaSinha/business-cards

Written answers (all assignment questions): ASSIGNMENT.txt

Run locally with XAMPP: http://localhost/shopify/index.php

Price is quantity + paper. Size does not change the price.

100  matte $20 / glossy $25
500  matte $80 / glossy $100
1000 matte $140 / glossy $180

index.php = product page
price.php = JSON price
add-to-cart.php = upload + session cart
cart.php = cart
database/schema.sql = schema
